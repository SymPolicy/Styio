# Plan Reports

**Purpose:** Define the optional evidence-report collection under `docs/plan/`; active plans remain in the parent directory, and generated inventory lives in [INDEX.md](./INDEX.md).

**Last updated:** 2026-07-04

## Scope

1. Store only evidence reports that still support active plans, ADR follow-up, or pending acceptance work.
2. Do not use reports as the source of truth for language semantics, workflow rules, or repository ownership.
3. Move durable conclusions into the owning plan, runbook, ADR summary, or rollup before deleting obsolete report files.
